Website God Mode is a small browser tool for developers. It brings together searches for Wikipedia, GitHub, development boards, vehicles, stocks, and project ideas in one place.

The site is built with plain HTML, CSS, and JavaScript. It needs no login or backend. Some results may take time because they come from public APIs.

Open index.html in a browser to run it, or visit https://omguptaogwhitehathacker-svg.github.io/GOD-MODE-WEBSITE-/.
