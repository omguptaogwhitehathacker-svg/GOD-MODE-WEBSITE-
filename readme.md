I made this project specially for developers it is quick lightweight easy to use and has no login authentication or any other formalities
it has multiple archives linked together in one static site you can gather info about vehicles, stocks, or basically any random thing that pops in your head 
it has been coded in vanilla html/css/js
it is slow sometimes because opensource api's however most of the time it works pleasurably
to run simply add all the files in the repo to a folder and double click the "index.html" to open it or visit site (https://omguptaogwhitehathacker-svg.github.io/GOD-MODE-WEBSITE-/) to try it out in the web
